# c0de paint

A companion mod of [c0de](https://github.com/joernott/minecraft-c0de) for Minecraft (Fabric and NeoForge). Its library `c0de_paint/cpaint` draws lines, flat shapes and bodies into canvases, combines and transforms them, and builds them in the world.

```
INCLUDE c0de_paint/cpaint
VARIABLE c TYPE c0de_paint/cpaint/CANVAS
```

- [Concept](docs/concept.md)
- [Implementation plan](docs/implementation_plan.md)
- [Development environment](docs/development_environment.md)

c0de paint requires c0de 0.7.0 or later. It is in development; nothing is released yet.
