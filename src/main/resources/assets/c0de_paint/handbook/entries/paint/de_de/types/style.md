Ein Stil legt fest, wie ein Teil einer Form gezeichnet wird: gar nicht, mit Luft, mit einem Block, mit zufälligen Blöcken, mit einem Verlauf oder mit einem Muster. Stile entstehen mit den STYLE-Funktionen. Eine neue Variable enthält STYLE\_NONE.

```c0de
VARIABLE brick TYPE c0de_paint/cpaint/STYLE
```
