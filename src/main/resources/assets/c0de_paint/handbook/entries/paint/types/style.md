A style says how a part of a shape is drawn: not at all, with air, with one block, with random blocks, with a gradient or with a pattern. Styles are made with the STYLE functions. A new variable holds STYLE\_NONE.

```c0de
VARIABLE brick TYPE c0de_paint/cpaint/STYLE
```
