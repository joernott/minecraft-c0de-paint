Programs that use the library include it with INCLUDE c0de\_paint/cpaint. Its types and functions start with the library name, like c0de\_paint/cpaint/DRAW\_BOX. The name is a wink at Deluxe Paint, which everybody called DPaint.

A program draws into a **canvas**, a three-dimensional grid of voxels, and builds it in the world with RENDER\_CANVAS. A **style** says how a line, a face or the inside of a shape is drawn.
